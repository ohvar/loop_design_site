Decisions

  • Each site wears its name as a coloured badge, so a screenshot alone tells you which environment it came from.
  • The app proves itself: it shows which commit is running, and one button writes to the database and reads the count back.
  • Prod is honest when it is empty: it says nothing has been promoted yet, instead of showing a broken page.
